# 라오스 4박 5일 — 남자 6명 (2027.01.14–18)

42~59세 남성 6명, 인천 출발 4박 5일. 비엔티안 IN / OUT, 고속철로 방비엥·루앙프라방을 묶는
건기 일정입니다.

## 왜 라오스인가

목적지 후보에서 다음이 차례로 제외되었습니다.

| 제외 | 사유 |
|---|---|
| 대만 | 오향·팔각이 음식의 뼈대라 회피 불가 |
| 후쿠오카·벳푸 | 1월 3~9℃, "겨울 탈출"과 상반 |
| 필리핀 클락 | 골프 빼면 남는 것이 없음 |
| 캄보디아 씨엠립 | 안전 우려 (시엠립 자체는 1단계) |
| 베트남 · 필리핀 · 홍콩 | 멤버 전원 방문 경험 |
| 태국 치앙마이 | 고수·피시소스 — 음식 문제 재발 위험 |

남은 조건(따뜻할 것 / 걸어서 볼 것 / 음식이 순할 것 / 안 가본 곳)을 모두 통과한 곳이
라오스입니다.
