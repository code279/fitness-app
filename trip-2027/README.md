# 도쿄 3박 4일 — 남자 6명 (2027.01.14–17, 청주 출발) · **확정**

42~59세 남성 6명. 청주공항 출발, 도쿄 신주쿠 2박 + 하코네 료칸 1박.

| 항목 | 내용 |
|---|---|
| 가는 편 | 에어로케이 **RF392** 청주 07:20 → 나리타 09:40 |
| 오는 편 | 에어로케이 **RF323** 나리타 19:35 → 청주 21:55 |
| 숙박 | 신주쿠 1/14·1/16 + 하코네 료칸 1/15 |
| 1인 예산 | 130~165만원 |

2026/27 동계 스케줄은 아직 미발표입니다. 위 시각은 확정된 2026 하계 기준이며
10월 초 판매 개시 후 30분 안팎 조정될 수 있습니다.

## 왜 도쿄로 갔나

| 탈락 | 사유 |
|---|---|
| 대만 | 오향분·팔각이 음식의 뼈대라 회피 불가 + 청주 하루 1왕복이라 실질 체류 2.5일 |
| 후쿠오카·벳푸 | 1월 3~9℃, "겨울 탈출"과 상반 |
| 필리핀 클락 | 골프를 빼면 남는 것이 없음 |
| 캄보디아 씨엠립 | 안전 우려 |
| 베트남 · 필리핀 · 홍콩 | 멤버 전원 방문 경험 |
| 라오스 · 말레이시아 · 치앙마이 | 음식 리스크 또는 선호 불일치 |
