# 도쿄 3박 4일 — 남자 6명 (2027.01.14–17, 청주 출발) · **확정**

42~59세 남성 6명. 청주공항 출발, 도쿄 신주쿠 2박 + 하코네 료칸 1박.

## 확정 사항

| 항목 | 내용 |
|---|---|
| 가는 편 | 에어로케이 **RF392** 청주 07:20 → 나리타 09:40 |
| 오는 편 | 에어로케이 **RF321** 나리타 **12:55** → 청주 15:25 *(동계 기준)* |
| 숙박 | **니시신주쿠** 1/14·1/16 + 하코네 료칸 1/15 |
| 최우선 조건 | **지진 안전 — 서쪽 고지대만 다님** |
| 신사 | 방문 없음 |
| 1인 예산 | 170~220만원 *(예산 제약 없음 반영)* |

2026/27 동계 스케줄은 아직 미발표입니다. 위 시각은 확정된 2026 하계 기준이며
10월 초 판매 개시 후 30분 안팎 조정될 수 있습니다.

## 지진 안전 설계

이번 여행의 1순위 조건입니다.

- **숙소·동선을 서쪽 고지대(니시신주쿠·시부야)로 고정.** 무사시노 대지 위라 지반이
  단단하고 액상화 위험이 낮으며, 고층 호텔은 면진·제진 구조입니다.
- **아사쿠사·우에노·긴시초·스미다·아라카와를 일정에서 제외.** 에도시대 저지대
  연약지반에 목조 밀집으로, 도쿄도 지역위험도 조사에서 화재·붕괴 위험 최상위입니다.
  이 때문에 센소지와 스카이트리가 빠졌습니다.
- **피난장소**: 신주쿠 중앙공원(광역피난장소), 도쿄도청(재해대책본부) — 둘 다 도보권.
  1/14 도청 전망대에서 위치를 눈으로 확인하는 것이 일정에 포함돼 있습니다.
- **필수 앱 3종**: Safety tips(일본 관광청 공식·한국어), 유레쿠루 콜, NHK World-Japan.
  한국에서 미리 설치하고 알림 권한까지 켜둡니다.
- **하코네는 활화산 지대**입니다. 오와쿠다니는 2015·2019년 분화경보로 통제된 전례가
  있어, 출발 2주 전과 전날 기상청 화산 경보 레벨을 확인합니다.

## 쇼핑 — 1/14 오후

골프·캠핑·유아용품 세 수요를 첫날 오후에 몰았습니다.

| 대상 | 장소 | 비고 |
|---|---|---|
| 골프 | **Alpen TOKYO** 6–7F | 클럽·의류·슈즈 |
| 캠핑 | **Alpen TOKYO** 4–5F | 스노우피크 등 |
| 유아용품 | 돈키호테 + 마츠모토키요시 | 아카찬혼포 긴시초점은 지진 위험지역이라 제외 |

Alpen TOKYO는 신주쿠역 동쪽 출구 도보 1분, 10개 층에 약 35만 점. 면세는 5,500엔 이상.

## 왜 도쿄로 갔나

| 탈락 | 사유 |
|---|---|
| 대만 | 오향분·팔각이 음식의 뼈대라 회피 불가 + 청주 하루 1왕복이라 실질 체류 2.5일 |
| 후쿠오카·벳푸 | 1월 3~9℃, "겨울 탈출"과 상반 |
| 필리핀 클락 | 골프를 빼면 남는 것이 없음 |
| 캄보디아 씨엠립 | 안전 우려 |
| 베트남 · 필리핀 · 홍콩 | 멤버 전원 방문 경험 |
| 라오스 · 말레이시아 · 치앙마이 | 음식 리스크 또는 선호 불일치 |
