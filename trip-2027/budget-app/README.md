# 여행 예산 앱 (Netlify + Supabase)

일행이 함께 쓰는 공금 지출 기록 앱. 구글 시트 + 앱스크립트 버전을 옮긴 것이다.

- **데이터베이스**: Supabase `meal-plan` 프로젝트 안의 별도 스키마 `trip_budget`
  (API에 노출되지 않음). 앱은 `public.trip_*` 함수로만 읽고 쓰며, 모든 함수가
  여행 코드를 확인한다. 여행 코드는 초대 링크(`#코드`)로만 전달하고 저장소에
  절대 커밋하지 않는다.
- **지갑**: 트래블카드 ①(숙소·교통) · 트래블카드 ②(식당·현지 먹거리) · 엔화 현금 · 원화
- **지출 입력**: 손입력 / 글자 붙여넣기(라이브 텍스트·구글 렌즈) / 앱 안 사진 인식(Tesseract.js)
- 영수증·캡처 원본은 보관하지 않는다.

## 마이그레이션
`supabase/migrations/` — 적용 순서대로.

## 앱 (web/)
빌드 과정 없는 정적 사이트. Netlify 에서 이 저장소를 연결하고 **Base directory 를
`trip-2027/budget-app/web`** 으로 지정하면 된다(빌드 명령 없음).

- `app.js` 화면 · `api.js` 데이터베이스 호출(+ `?demo` 체험 모드) · `parse.js` 영수증·카드 내역 글자 해석
- 사진 글자 인식은 Tesseract.js 를 처음 누를 때 CDN 에서 받는다(영수증: 일본어+영어, 카드 캡처: 한국어+일본어+영어)
- 초대 링크: `https://<사이트>/#<여행 코드>`
- 아이콘: Lucide (ISC)

## 시험
- `npm test` — 글자 해석 단위 시험 (영수증 5종, 카드 내역 4종, 분류)
- `test/e2e.mjs` — 브라우저에서 입력·붙여넣기·사진 인식·수정·삭제·충전·설정 흐름
