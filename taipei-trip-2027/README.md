# 겨울 원정 2027.01.14–17 — 대만 / 도쿄 2안 (청주 출발)

42~59세 남성 6명, **청주공항 출발 3박 4일**. 최종 후보는 **대만**과 **도쿄** 둘입니다.

| | 대만 | 도쿄 |

## 대만안의 식당 선별 기준

멤버 일부가 대만 음식을 못 먹는 원인은 **오향분(五香粉)과 팔각(八角)** 입니다. 고수와 달리
"빼주세요"가 통하지 않는 재료여서, 이것이 뼈대인 메뉴는 일정에서 전부 제외했습니다.

- **제외** — 루러우판, 홍소(紅燒) 우육면, 취두부, 차예단, 지파이 오향분
- **완전 안전** — 딘타이펑, 첨호점(홍콩 딤섬), 삼미식당(일식), 푸항더우장, 石二鍋 샤부샤부,
  해산물 소금구이, 톈진충좌빙, 스무시하우스
- **조건부** — 융캉우육면은 반드시 청탕(清燉), 마라훠궈는 백탕+마라 반반솥
- **주문용 문장** — `不要香菜`(고수 빼주세요) / `不要五香粉`(오향분 빼주세요) / `清燉`(맑은 국물)
